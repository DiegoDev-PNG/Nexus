Nexus é um e-commerce no qual você consegue comprar itens de tecnologia de forma segura e barata, venha conferir as ofertas :)

Linguagens de Programação e Tecnologias Usadas

HTML5 & CSS3: Utilizados para a estruturação básica das páginas e para a estilização visual dos elementos.

JavaScript: Empregado para adicionar dinamicidade e lógica às aplicações, como manipulação de dados e respostas a interações do usuário.

Tailwind CSS: Utilizado como framework de estilo utility-first, permitindo a construção rápida e personalizada de interfaces de forma responsiva.

Astro: Framework focado em performance e entrega de conteúdo, explorado para criação de sites mais rápidos e otimizados.

Forma como Foram Utilizadas

Sistemas E-commerce e Lógica de Negócio: Aplicação de JavaScript na criação de funcionalidades práticas, tais como gerenciamento de carrinhos de compras, simulação de fluxos de pagamento e autenticação de usuários.

Design e Interface Responsiva: Uso do Tailwind CSS junto ao HTML/CSS para estruturar layouts modernos, garantindo adaptação a diferentes tamanhos de tela.
